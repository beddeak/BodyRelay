# BodyRelay

여러 플레이어가 하나의 몸을 교대로 조종합니다.

[다운로드](https://github.com/beddeak/BodyRelay/releases/latest)

## 설치 및 설정

Paper 26.3 · Java 25. 새 서버는 서버팩 ZIP을 빈 폴더에 풀고 Windows에서 `start.bat`을 실행하세요. 첫 실행 후 생성된 `eula.txt`를 읽고 동의하면 값을 변경한 뒤 다시 실행하세요. 기존 서버는 정지 후 `BodyRelay-1.0.0.jar`을 `plugins/`에 넣고 다시 시작하세요.

첫 실행 후 `plugins/BodyRelay/config.yml`을 편집하세요. 서버를 정상 종료하고 편집한 뒤 다시 시작하면 새 설정을 읽습니다. [기본 설정과 항목별 설명](src/main/resources/config.yml)

기본 명령어는 `/change`이며 `/bodyrelay`도 사용할 수 있습니다.

## 명령어

`/change` (별칭 `/체인지`, `/교대`, `/relay`). `status`, `help` 외에는 `change.admin` 권한(기본 OP)이 필요합니다.

| 명령어 | 설명 |
| --- | --- |
| `start [첫 조종자]` (시작) | 접속한 사람으로 순서를 섞어 시작. 첫 조종자를 지정할 수 있음 |
| `stop` (종료) | 끝내기. 조종자는 몸을 가진 채 남고, 대기실 사람들은 조종자 옆으로 돌아옴 |
| `pause` / `resume` (일시정지 / 재개) | 타이머만 멈춤 / 다시 진행 |
| `now` (지금·교대) | 지금 바로 다음 사람에게 교대 |
| `switch <이름>` (넘기기) | 지금 바로 그 사람에게 교대 |
| `next <이름>` (다음) | 다음 차례 지정. `next`만 치면 다음 사람 확인 |
| `order [이름 ...]` (순서) | 순서 보기. 이름을 주면 그 순서대로 앞에 세움 |
| `join` / `leave <이름>` (참가 / 제외) | 참가시키기 / 빼기(저장됨). 조종 중인 사람을 빼면 먼저 다음 사람에게 넘김 |
| `interval <시간>` (주기) | 한 턴 시간 변경(저장됨) |
| `time <시간>` (시간) | 이번 교대까지 남은 시간을 직접 지정 |
| `add <시간>` (연장) | 남은 시간 늘리기. `add -10`이면 줄이기 |
| `status` (상태) | 조종자·다음 차례·남은 시간. 관리자에게는 몸의 체력·위치도 보임(대기 중인 관리자에게는 숨김) |
| `reload` | config.yml 다시 읽기 |

시간은 `30`, `90s`, `2m`, `1m30s`, `1분30초`, `1h`처럼 쓸 수 있습니다.
